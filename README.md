# الجدول الدوري ثلاثي الأبعاد

تجربة تفاعلية تعمل في المتصفح، وتتكيف مع شاشات الجوال والجهاز اللوحي والحاسب.

**عمل الطالبة لمار محمد مجممي - إشراف معلمة المادة هالة الوقداني**

## ماذا تقدم التجربة

- ثلاث طرق عرض: الجدول، وأبراج الكتلة، والحلزون.
- تدوير وتكبير بالفأرة أو باللمس.
- الضغط على أي عنصر يعرض بياناته ونموذجًا ثلاثي الأبعاد لذرته.
- تمييز كل فئة من العناصر، والبحث بالاسم أو الرمز أو العدد الذري.

## النشر على GitHub Pages

1. فك ضغط الملف `periodic-table-3d.zip`.
2. أنشئ مستودعًا عامًا جديدًا في GitHub.
3. اختر **Add file** ثم **Upload files**.
4. اسحب محتويات مجلد `periodic-table-3d` إلى الصفحة، بحيث يكون `index.html` في جذر المستودع، ثم اضغط **Commit changes**.
5. افتح **Settings** ثم **Pages**، واختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، ثم **Save**.
6. بعد دقائق يظهر رابط التجربة في الصفحة نفسها.

## تعديل الكود

الملفات القابلة للتعديل في `src/`، والنسخة التي يشغلها المتصفح هي `assets/app.js`. بعد أي تعديل في `src/` نفّذ:

```
npm install
npm run build
```

لا يلزم ذلك عند تعديل `index.html` أو `assets/style.css`.
